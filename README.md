# 3D Endless Runner

A 3D Endless Runner game built in Unity 6 using the Built-in Render Pipeline.

## 🎮 Game Features
* **Custom Ball Controls:** Smooth physics-based movement and dynamic track navigation.
* **Infinite World Generation:** Dynamic track-following and continuous segment spawning.
* **Hazards & Scoring:** Avoid barrel hazards while collecting coins for high scores.
* **UI & HUD:** Real-time coin counter and gameplay interface.

## 🛠️ Built With
* **Engine:** Unity 6 (Built-in RP)
* **Language:** C#
* **IDE:** Visual Studio / VS Code

## 📁 Repository Structure
* `Assets/` - C# scripts, prefabs, materials, and game audio/models.
* `Packages/` - Unity package dependencies and manifest settings.
* `ProjectSettings/` - Project configuration, physics, and input setups.
